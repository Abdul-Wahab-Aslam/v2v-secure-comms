## Running the Python Pipeline

```bash
cd python
pip install -r requirements.txt
python simulation.py
```

This will:
1. Simulate 15,000 V2V telemetry records (Normal / Accident / Suspicious)
2. Train Isolation Forest, XGBoost, and LSTM models
3. Evaluate with Accuracy, Precision, Recall, F1, Latency
4. Save `web/data/results.json` and `web/data/simulation_sample.csv`

## Deploying to Vercel

```bash
npm install -g vercel
vercel login
vercel --prod
```

The `vercel.json` at the root routes all traffic to the `web/` folder.
